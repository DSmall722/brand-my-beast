# BrandMyBeast — P2 auth + soft auction scaffold

CAMPAIGN.md still wins. This file records the **P2** build choices so agents do not reopen them in drive-by PRs.

Updated: 2026-09-14

## Auth vendor (locked for P2)

**Choice: Auth.js (Auth.js / `next-auth` v5) on the App Router.**

Why this over Clerk / Neon Auth for v1:

- Stays inside the locked Next.js + Vercel stack without a second paid identity SaaS.
- Email magic-link / OAuth can land later; P2 only needs “account exists” for intent bids.
- Session lives on the server. No `localStorage` ledger.

### Wiring status

Routes and env scaffolding are in:

- `src/lib/auth/` — Auth.js config + mode gate
- `src/app/api/auth/[...nextauth]/route.ts` — Auth.js handlers
- `src/app/api/auth/status/route.ts` — mode/providers smoke (no secrets)
- `/signin`, `/account` — session UI
- `AUTH_MODE=test` — Credentials provider for CI/local (`@example.com` + `AUTH_TEST_PASSWORD`)

Live OAuth is optional. CI never needs GitHub secrets.

### Env vars Dennard adds for live GitHub login

| Var | Required when | Notes |
|---|---|---|
| `AUTH_SECRET` | `AUTH_MODE=live` | `openssl rand -base64 32` |
| `AUTH_URL` | production | e.g. `https://brandmybeast.com` |
| `AUTH_GITHUB_ID` | live GitHub | GitHub OAuth App client id |
| `AUTH_GITHUB_SECRET` | live GitHub | GitHub OAuth App client secret |
| `AUTH_MODE` | always set in prod | `live` on production; `test` for CI |
| `AUTH_ENABLE_TEST_LOGIN` | optional | `1` keeps test credentials on a live deploy |
| `AUTH_TEST_PASSWORD` | test login | defaults to `test` |

Do **not** add Clerk, Supabase Auth, or Firebase Auth without a PR that rewrites this section.

## Soft auction (intent only)

P2 standing bids are **intent**, not capture:

- Record who wants which panel at what mark.
- Show deposit **20%** as an amount owed later — never charge a card on P2.
- Operator approval / veto stays manual.
- No Stripe SetupIntent, no `CLOSE_AT`, no 30-day clock.

Domain helpers live in `src/lib/intent.ts`. Persistence is `src/lib/intent-store.ts`:

- **Memory** when `INTENT_MODE=memory` (Playwright/CI) or no `DATABASE_URL` outside production.
- **Postgres** table `intent_bids` (Drizzle + Neon) when `DATABASE_URL` is set — still intent-only; no Stripe columns. Apply `drizzle/0001_intent_bids.sql` (or `npm run db:push`) once per environment.

Panel pages live at `/panels/[panelId]`. Operator approval thread: `/operator/approvals` (`OPERATOR_EMAILS`, or any `@example.com` user when `AUTH_MODE=test`).

Waitlist → intent handoff: after join, the homepage waitlist form shows CTAs to `/#panels` and `/signin?callbackUrl=/panels/hood`. Account offers a direct Hood intent link. Still no capture.


Public seat page: `/panels/[panelId]` is the public seat surface — occupancy, standing brand/trade, etch lock, waitlist CTA, intent-only. Still no capture.

Honest shortfall ticker: homepage board shows intent-pledged dollars, shortfall to floor/buyout, and open seats from the intent ledger. No day-count and no close clock.

Visual vault: homepage money board tracks fill on a 0→$120,000 buyout scale with markers at the $58,000 floor and $120,000 buyout. Progress copy still reports % of floor and % of buyout. Still no close clock.

Wreck & refund rules: homepage `#wreck` publishes the three RULES.md outcomes (campaign miss / wrap pro-rata / immortal fragment). Contract text only — no Stripe cash path.

Stainless compositor: `/panels/[panelId]` mockup toggles wrap vs etch preview on steel (etchable panels only). Etch remains preview-locked under buyout. Still no capture.

Same-day Imagine mockup scaffold: operator approvals can queue wrap/etch placeholder mockups for listed intents (`ImagineMockupControls`). Memory store only — no billable Imagine API, no Stripe.

Highway-legibility checker: intent brand field live-checks wordmark length and etch-forbidden terms (RULES.md). Soft warn/fail hints only — still no capture.

Etch constraint linter: stainless compositor etch mode shows RULES.md etch checklist + optional art-notes lint (`EtchConstraintLinter`). Soft guidance only — still no capture.

Adjacent-panel clash detector: panel seats show neighboring standing brands; intent brand field soft-warns on same-brand / overlap with adjacent holders (`AdjacentClashHint`). Guidance only — still no capture.

Artwork approval thread: `/operator/approvals` shows the RULES artwork checklist on pending cards, requires an operator note on reject, and keeps a decided log. Reject notes surface on the bidder account. Memory notes only — still no capture.
